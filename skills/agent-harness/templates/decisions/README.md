# Architecture Decision Records

ADRs record engineering decisions that have been accepted and affect later
implementation. They explain **why**; the **how** lives in architecture docs,
specs, and code.

| ADR | Status | Decision |
| --- | --- | --- |
| [0001](0001-<short-name>.md) | accepted | <one-line summary> |

New ADRs use the next incremented number and must include Context, Decision,
and Consequences. Create from
[`ADR-TEMPLATE.md`](../ADR-TEMPLATE.md).

Accepted ADRs are never edited in place; create a new ADR and mark it as
superseding the old one. Add a row to this table when creating an ADR.
